title: Keyboard shortcuts
description: One palette and ten keys. Enough to run the whole app without reaching for the mouse.
---

## The palette

<kbd>⌘</kbd> <kbd>K</kbd> — or <kbd>Ctrl</kbd> <kbd>K</kbd> — opens the command
palette. Results are grouped: actions, then navigation, then your tasks and
projects. Type a few letters of anything.

| Key | In the palette |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move the cursor |
| <kbd>↵</kbd> | Open the highlighted result |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Complete the highlighted task |
| <kbd>⇧</kbd> <kbd>↵</kbd> | Move the highlighted task to Today |
| <kbd>Esc</kbd> | Close |

## In a list

| Key | Does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move between rows |
| <kbd>↵</kbd> | Open Task Detail |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Complete the focused task |
| <kbd>⇧</kbd> <kbd>↵</kbd> | Move it to Today |
| <kbd>N</kbd> | Focus the composer |
| <kbd>Esc</kbd> | Close the detail panel, or blur the composer |

## In the composer

| Key | Does |
| --- | --- |
| <kbd>↵</kbd> | Save and keep composing |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Save and close |
| <kbd>Esc</kbd> | Discard |

:::tip
The focused row shows its own key hints, so you don't have to remember this
page. It is here for the first week.
:::
